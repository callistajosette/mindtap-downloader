I created this for personal use because I hate the Cengage MindTap textbook reader interface, and prefer to use/annotate textbook printouts in onenote. This is designed with the intent of capturing at the chapter level, and will run from whatever page you start on until the end of chapter and output to pdf. If you need to specify a certain # of pages, set TEST_MODE_MAX_PAGES and begin on a page other than the first page of a chapter.

## Requirements
The only requirement to run this is a local docker installation, everything else should be local to the project. Also, disclaimer, yes, the way ai suggested a script to call the docker stuff is weird and gross. I didn't really care as long as things were functional enough for my purpose. If you'd like to improve feel free to submit a PR.
